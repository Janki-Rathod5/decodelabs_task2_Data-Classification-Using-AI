# 🌸 Data Classification Using AI

## 📌 Project Overview

This project was developed as part of the **DecodeLabs AI Internship - Project 2**.

The objective of this project is to classify Iris flowers into different species using Machine Learning algorithms. The application loads the Iris dataset, performs data exploration and visualization, trains multiple classification models, evaluates their performance, and predicts the flower species based on user input.

---

## 🚀 Features

* Load the Iris dataset
* Explore dataset information
* Display statistical summary
* Generate data visualizations
* Train Decision Tree Classifier
* Train K-Nearest Neighbors (KNN) Classifier
* Compare model accuracy
* Automatically select the best model
* Generate Classification Report
* Display Confusion Matrix
* Save trained model using Joblib
* Load saved model
* Predict flower species using user input
* Input validation and error handling

---

## ▶️ How to Run

1. Clone the repository

```
git clone <repository-url>
```

2. Install dependencies

```
pip install -r requirements.txt
```

3. Run the project

```
python classification_model.py
```

## 📊 Machine Learning Models
